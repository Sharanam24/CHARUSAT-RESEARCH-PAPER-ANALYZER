About CHARUSAT Research Analyzer

Understanding our mission and technology

Project Overview

The CHARUSAT Research Analyzer is a comprehensive web-based research analysis portal designed specifically for CHARUSAT University. Our system enables efficient collection, analysis, and management of research papers while providing powerful analytics and insights into research output.

The platform serves as a centralized hub for tracking academic publications, understanding research trends, and maintaining accurate author attribution across the university's diverse research portfolio.

AI/ML Technologies

The cornerstone of our system is the AI-powered Duplicate Author Detection capability. This innovative feature uses machine learning algorithms to:

  • Name Variation Detection: Identify different spellings and formats of author names (e.g., "John Smith", "J. Smith", "Smith, J.")
  • Similarity Scoring: Calculate confidence scores (0-100) indicating the likelihood that name variations refer to the same person
  • Intelligent Grouping: Automatically group author name variations to maintain accurate research attribution
  • Pattern Recognition: Learn from naming patterns to improve detection accuracy over time

This AI/ML capability ensures that research output is correctly attributed to authors, even when their names appear in different formats across various publications.

Technology Stack

  • Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
  • Layout: CSS Flexbox and Grid for responsive design
  • Data Visualization: Canvas API for charts and analytics
  • API Communication: Fetch API for backend integration
  • Architecture: Modular JavaScript with separation of concerns
