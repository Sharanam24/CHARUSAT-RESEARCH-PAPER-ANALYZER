🔍 Detailed Test Cases

Test Case 1: Navigation Presence

Steps:

  1. Open each page (Home, Papers, Authors, Analytics, About)
  2. Verify navigation bar is present at the top
  3. Verify all 5 links are visible

Expected Result: Navigation bar with all 5 links is present on every page

Test Case 2: Active Page Highlighting

Steps:

  1. Open Home page - verify "Home" link has light blue background
  2. Open Papers page - verify "Papers" link has light blue background
  3. Open Authors page - verify "Authors" link has light blue background
  4. Open Analytics page - verify "Analytics" link has light blue background
  5. Open About page - verify "About" link has light blue background

Expected Result: Current page link is highlighted with class="active" and light blue background

Test Case 3: Navigation Functionality

Steps:

  1. Start on Home page
  2. Click "Papers" link - verify navigation to papers.html
  3. Click "Authors" link - verify navigation to authors.html
  4. Click "Analytics" link - verify navigation to analytics.html
  5. Click "About" link - verify navigation to about.html
  6. Click "Home" link - verify navigation back to index.html

Expected Result: All navigation links work correctly and navigate to the correct pages

Test Case 4: Hover Effects

Steps:

  1. Open any page
  2. Hover over each non-active navigation link
  3. Verify light blue background appears on hover
  4. Verify hover effect has smooth transition

Expected Result: Non-active links show light blue background on hover with smooth transition

Test Case 5: Responsive Navigation

Steps:

  1. Open any page in browser
  2. Resize browser window to 768px width or less
  3. Verify navigation adapts to smaller screen
  4. Verify all links remain accessible

Expected Result: Navigation adjusts layout for tablet/mobile screens while maintaining functionality

Test Case 6: Keyboard Navigation

Steps:

  1. Open any page
  2. Press Tab key repeatedly
  3. Verify focus moves through navigation links
  4. Press Enter on a focused link
  5. Verify navigation occurs

Expected Result: All navigation links are keyboard accessible and functional
